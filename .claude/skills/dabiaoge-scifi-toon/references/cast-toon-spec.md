# 角色卡通化规格（Sci-Fi Sitcom Toon 引擎用）

来源：`characters/<name>-prompt.md` 的「固定特征」与配色、`characters/<name>-sheet.png`。这里把它们翻译成 toon.js / chars.js 能直接用的造型、表演和声音参数。设定文件更新时以设定文件为准，并同步改这里。

## 全片通用

| 项 | 值 |
|---|---|
| 描边 | `#2A1F33`（偏紫的近黑，设定图同色），角色/道具 ~7 px，背景细节 4–6 px，屏幕空间恒定线宽 |
| Boil | 屏幕空间 ~7 px 重采样，法向噪声 ~1.7 px，3 张循环 @12 fps |
| 眼白 | 所有世界不变（表哥的镜片 `#E6F6FF` 是镜片色，镜片后眼白照常） |
| 阴影 | 每个形体一块硬边深色，裁在填色内，背光侧；不用渐变 |
| 设定图背景 | 暖米色 `#F1ECE3` 左右，仅用于 model sheet，不作为任何"世界"的底色（"可疑的正常世界"除外） |
| 字幕说话人胶囊色 | 表哥 `#2A2A33` 白字；小米 `#D8343C`；三姑 `#8A2A5A`；奶奶 `#8A2A2A`（金字 `#FFCC33`） |

剪影检查：四人全涂黑并排，必须一眼认出——表哥（圆头 + 一根卷毛 + 宽马甲梯形）、小米（刺头 + 窄肩）、三姑（大蓬头 + 耳环圆点）、奶奶（矮 + 头顶发髻）。

## 表哥 Biaoge — 面瘫担当（deadpan）

- **造型**：圆胖；头是大正圆、光头，头顶**一根卷曲的头发**（一个小圈，boil 时轻微颤动）；**巨大的粗黑框圆眼镜**（框粗约 1.6× 描边，两片镜片几乎相切，镜片 `#E6F6FF` 加一道平涂高光弧）；镜片后眼睛**半闭、厚眼皮、瞳孔 4 px**；小圆鼻头；**一字平嘴**；大耳朵。
- **服装**：浅灰蓝睡衣 `#9AA3B5`，外套黑色绗缝羽绒马甲 `#2A2A33`（马甲上 4–6 条略弯的横向绗缝线，线色比马甲浅一级），马甲轮廓是下宽的梯形。
- **皮肤**：`#E9B88E`，阴影 `#C99168`；头顶一块浅色高光椭圆。
- **默认道具**：一手白米饭碗（碗沿蓝边、米饭要有颗粒感和一缕热气，否则读不成饭），一手木筷子；或缠胶布旧遥控器 + 大红键"回档"。
- **表情集**：面瘫（默认，眼皮压到瞳孔上沿）/ 吃饭（嘴一张一合，眼不动）/ 得意（一侧嘴角上挑 3–4 px、眼皮更低）/ 震惊（镜片后眼睛全开、瞳孔缩到 3 px、嘴变小 o 形）。震惊一集最多用一次，才值钱。
- **表演**：几乎不动；只有眨眼（慢、两拍）、筷子夹一口、瞳孔平移。台词前不做预备动作，反差就在这里。点头幅度由语音响度驱动但压到 ±1°。
- **配音**：低、平、慢。中文默认 edge-tts `zh-CN-YunjianNeural` 或 `zh-CN-YunyangNeural`，rate −10% 到 −15%；处理：轻饱和 + ~180 Hz 提升。按 DIRECTOR/TECHNIQUE 的方法实测 median f0，确保比小米低一档以上。
- **口头禅风格**：一两个字的打断（"不行。""回档。""吃饭。"），可做全片 callback。

## 小米 Xiaomi — 慌张担当（panic）

- **造型**：瘦，窄肩；**乱糟糟的黑色刺头** `#1E1A24`（7–9 根不规则尖刺，越累越乱：刺的数量和长度是"疲劳度"参数）；**黑眼圈**（眼下两道弧 + 一块淡紫灰平涂）；大白眼、瞳孔 4–5 px；眉毛皱成"八"字。
- **服装**：红色过年毛衣 `#D8343C`、阴影 `#A8242C`；胸前一圈白色菱形雪花带 `#FFFAF0`，下面一条细白杠。
- **皮肤**：`#F0C49A`，阴影 `#D39E74`。
- **默认道具**：缠**黄色胶布**的旧电视遥控器，大红键写"回档"，天线头在按下时亮（亮色 = portal 发光色）。
- **表情集**：慌张（默认）/ 心虚（瞳孔侧移、嘴角下撇、冒汗滴）/ 憔悴（刺头更乱、眼袋更深、身体塌）/ 装酷（黑墨镜 + 小得意笑）。
- **表演**：nervous jitter（12 fps 随机偏移 3–6 px + 瞳孔颤），幅度随恐慌度增加；每次按"回档"前要有预备（缩肩、拇指抬高）；尖叫时嘴 ×1.5–1.9。
- **配音**：高、快、有气息。默认 `zh-CN-YunxiNeural`，rate +10% 到 +15%；处理：presence 提升。
- **注意**：`xiaomi-prompt.md` 设定为年轻男上班族，而 `skills/xiaomi-magic-tools-ip` 的文字里用"她"。视觉以角色设定图为准；如果本集剧情来自 xiaomi-magic-tools-ip，在 TREATMENT.md 里标出这个差异，并在唯一一轮提问里请用户确认。

## 三姑 Sangu — 加压担当（连珠炮）

- **造型**：五十岁出头；**紫红色蓬松泡面头** `#8A2A5A`（外轮廓用 10–14 个小圆弧拼成，额前一排小卷）；**大金色圆耳环** `#FFCC33`；**大红嘴唇** `#D8203A` + 嘴角小黑痣；淡蓝眼影、细弯眉、几根睫毛；笑眯眯。
- **服装**：橙黄豹纹上衣 `#E8A03A`，斑点 `#3A2414`（斑点是不规则平涂小块，boil 时跟着描边一起抖，但位置固定，不要每帧重新随机）。
- **皮肤**：`#F2C6A6`。
- **默认道具**：镶亮钻的粉色回档遥控器（只在后悔/重来主题出现；钻石的闪光是平涂四角星，不能用 portal 发光色）。
- **表情集**：咧嘴笑挥手（默认）/ 凑近盘问（眼睛发亮、身体前倾进画）/ 冷场假笑（笑僵住、一只眼抽搐）/ 眯眼坏笑（掏遥控器时）。
- **表演**：说话时一只手一直挥；问题"三连问 → 机关枪"最适合她：同一句"一个月挣多少？"越问越快。
- **配音**：嗓门大、热情，东北腔感觉。默认 `zh-CN-liaoning-XiaobeiNeural`（东北话），rate +5% 到 +10%；不可用时退回 `zh-CN-XiaoyiNeural`。

## 奶奶 Nainai — 一锤定音

- **造型**：矮小（身高约表哥的 0.75）；**白发头顶圆发髻** `#F4F1EA`；**金棕色细框圆老花镜**；眼角嘴角细皱纹（各 2 条短弧）；小圆鼻子；温和半眯、淡笑。
- **服装**：枣红中式棉袄 `#8A2A2A`、阴影 `#661C1C`，正中一排金色盘扣 `#FFCC33`（3–5 个）。
- **皮肤**：`#EFC8A8`，阴影 `#D4A886`。
- **默认道具**：木筷子；招牌道具是**巨大的金色回档遥控器**，底部红色"福"字——它是"终止回档"的终极按钮，只在结局用。
- **表情集**：慈祥眯眼笑（默认）/ 拍桌一锤定音（眼睁开、眉压下、嘴大张）/ 夸张晕倒（眼变 X）。
- **表演**：前面几乎只出现在背景里吃饭（可以做"她其实全程都看见了"的伏笔）；结局一拍桌，**全场静音 + 慢推**，再说一句话。
- **配音**：慢、慈祥、有分量。默认 `zh-CN-XiaoxiaoNeural` 降速（rate −15%）并下移 1–2 半音做老年感；或 `zh-CN-shaanxi-XiaoniNeural` 做方言版。

## 家的世界（默认）与回档世界

- **家 = 除夕年夜饭**：深红墙 + 金色窗花剪影、圆桌、红灯笼（灯笼不发光，只是平涂红 + 一圈深红阴影）、一碗碗白米饭。3–5 色以内。
- **回档世界**：每次回档换一套 3–5 色调色板，色相和明度都要与上一个世界拉开；同一机位（例如饭桌中景两人 + 三姑在右）重复，只变世界。
- **Portal 发光色**：从年夜饭主色之外挑一个（例如电光青 `#3FE0D0` 或时间蓝紫），全片只有回档漩涡和遥控器天线尖能用它。漩涡造型要原创（例如倒转的钟面 + 旋转的春联纸屑），绝不做绿色黏液门。
- **世界标签**：VT323 终端字体左上角打字出现，例如 `时间线 #23 · 除夕 19:42`，颜色按世界变化。
